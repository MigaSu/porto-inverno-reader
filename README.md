# 🍸 Porto Inverno: Chronicles & Lore Reader (1931)

Интерактивный веб-ридер, архив саммари и досье персонажей для детективной ролевой кампании в жанре нуар **«Порто-Инверно»**.

🌐 **Онлайн-сайт кампании:** [https://migasu.github.io/porto-inverno-reader/](https://migasu.github.io/porto-inverno-reader/)

---

## 🌟 Возможности ридера:
1. **📖 Хроники сессий (24 главы):**
   - Удобная навигация по сюжетным линиям (*Молли и Хизер*, *Эйден и Малкольм*, *Соло-сессии*).
   - Расчет времени чтения, таймлайн и регулировка размера шрифта (`A-` / `A+`).
2. **👤 Досье персонажей (35+ NPC):**
   - Полнотекстовый поиск в реальном времени.
   - Фильтрация по статусам (*Жив, Погиб, В бегах, Ранен*) и фракциям (*Синдикат Фишера, Команда Крауча, Эль Гринго, Мэрия*).
   - Подробные карточки предыстории и связей между героями.
3. **📋 Интеграция с Telegram:**
   - Кнопка **«В Telegram»** на каждой главе и карточке для мгновенного копирования с разметкой.
   - Вкладка **Telegram Hub** с живым предпросмотром сообщений.

## 🚀 Как включить GitHub Pages (Сайт для игроков)
1. Откройте репозиторий: [https://github.com/MigaSu/porto-inverno-reader](https://github.com/MigaSu/porto-inverno-reader)
2. Перейдите в **Settings** (Настройки) → **Pages**.
3. В поле **Build and deployment** / **Branch** выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Сайт станет доступен по адресу: `https://migasu.github.io/porto-inverno-reader/`.

---

## 📱 Как встроить в Telegram (Telegram Mini App)
1. Напишите боту [@BotFather](https://t.me/BotFather) в Telegram.
2. Выберите команду `/setmenubutton` (или `/newapp`).
3. Укажите ссылку на сайт: `https://migasu.github.io/porto-inverno-reader/`.
4. Игроки смогут открывать архив прямо внутри Telegram!
